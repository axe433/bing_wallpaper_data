**Nage droit devant toi !**

À Lighthouse Reef, près de l’île de Cabilao aux Philippines, le faux poisson-clown évolue dans un décor aussi magnifique qu’hostile. Dans ces eaux tropicales saturées de prédateurs, il a trouvé un refuge inattendu : l’anémone de mer, dont les milliers de cellules urticantes dissuadent presque tous les intrus. Là où d’autres verraient un piège, il trouve un abri parfait.
